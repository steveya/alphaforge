# Alphaforge

Alphaforge provides composable primitives for point-in-time feature engineering and dataset building for systematic research.

## What you get

- Declarative dataset specs (`DatasetSpec`) for reproducible builds
- Calendar-aware feature alignment and join policies
- Public web data loader pack for macro and derivatives signals
- Point-in-time (PIT) revision-aware storage and query workflows
